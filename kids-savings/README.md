# Kids Savings Tracker: Numbers + Shortcuts

`Kids Savings.numbers` is a native Apple Numbers document, not Excel. It was
generated by `build_tracker.py` with the `numbers-parser` library.

**Limitation:** no tool outside Apple's apps can write live Numbers formulas.
The file has all 32 transactions, dollar formatting, colours and layout, but the
balance cells say *formula needed*. Part B adds 7 short formulas (about 3 minutes).

## What's in the file

| Sheet    | Table                 | Columns                          |
|----------|-----------------------|----------------------------------|
| Overview | `Overview`            | Savings, Balance                 |
| Avelyn   | `Avelyn Savings`      | Current Savings (big number)     |
| Avelyn   | `Avelyn Transactions` | A Date, B Amount, C Balance      |
| Samuel   | `Samuel Savings`      | Current Savings (big number)     |
| Samuel   | `Samuel Transactions` | A Date, B Amount, C Note, D Balance |

The transaction tables have no blank rows. "Add Values to Bottom of Table"
puts each new row directly under the last transaction.

The amounts were checked independently: Avelyn has 16 transactions totaling
$81.25, Samuel has 16 totaling $49.25, and the combined total is $130.50.

---

## A. Put the file in iCloud Drive
1. Download `Kids Savings.numbers` to your iPhone.
2. In **Files**, move it to **iCloud Drive › Numbers**.
3. Tap it once so it opens in Numbers.

## B. Add the formulas (one time only)
Tap a cell, type the formula exactly as shown, then tap ✓.

**Avelyn sheet**
1. Cell **C2** (Balance column, first row): `=B2`
2. Cell **C3**: `=C2+B3`. Copy **C3**, select **C4** down to **C17**, and paste. **C17** should show **$81.25**.
3. Big number cell next to *Current Savings*: `=SUM(Avelyn Transactions::B)` → **$81.25**

**Samuel sheet**

4. Cell **D2**: `=B2`
5. Cell **D3**: `=D2+B3`. Copy **D3**, select **D4** down to **D17**, and paste. **D17** should show **$49.25**.
6. Big number cell next to *Current Savings*: `=SUM(Samuel Transactions::B)` → **$49.25**

**Overview sheet**

7. Avelyn's Balance: `=Avelyn Savings::B1`
   Samuel's Balance: `=Samuel Savings::B1`
   Combined Total: `=B2+B3` → **$130.50**

The *Current Savings* and Overview numbers add up the whole Amount column. New
rows from the Shortcut are included automatically, and these totals don't rely
on the per-row Balance column.

## C. Finish the **Kids Savings** Shortcut
Open Shortcuts and tap **Kids Savings** to edit it. Final action order:

1. **Ask for Input** (already done): Number, prompt `How much?`, negatives and decimals on.
2. Add **Format Date** directly under it.
   - Date: **Current Date**
   - Date Format: **Custom**, then type `M/d/yyyy`
   - This saves a fixed date, so old rows never change.
3. **Choose from Menu** (already done): prompt `Which child?`, options **Avelyn** and **Samuel**.
4. Under **Avelyn**, in **Add Values to Bottom of Table**:
   - Document: **Kids Savings** (in iCloud Drive › Numbers)
   - Sheet: **Avelyn**
   - Table: **Avelyn Transactions**
   - Values, in this order: **Formatted Date**, then **Provided Input**
5. Below it, still under **Avelyn**, add **Show Notification**:
   `Saved Provided Input for Avelyn on Formatted Date`
6. Under **Samuel**, add the same two actions, using Sheet **Samuel** and Table **Samuel Transactions**.
7. Tap **Done**. Test it with `0.01` for Avelyn. Check the new row, then delete it in Numbers.

## D. Share with your wife
1. In Numbers, open the file and tap the **Collaborate** button.
2. Choose **Only invited people → Can make changes**, then send it to her by Messages.
3. She taps the link once to open the file in Numbers.
4. On your phone, open Shortcuts, long-press **Kids Savings**, and choose **Share → Copy iCloud Link**. Send her the link.
5. She adds the Shortcut. In each **Add Values to Bottom of Table** action she taps **Document** and picks the shared **Kids Savings** file.

## Rebuilding the file
```
pip install numbers-parser
python3 build_tracker.py
```
The script checks the 32 transactions and the three totals before it saves.
